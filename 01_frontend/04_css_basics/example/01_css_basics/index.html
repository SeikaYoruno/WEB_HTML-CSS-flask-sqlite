CSSの書き方と単位

CSSを書く3つの場所

① 外部ファイル（css/01_style.css）で青色にしている段落

② <style>タグで橙色にしている段落

③ style属性で緑色にしている段落

色の指定方法

名前
royalblue
16進数
#3f6fd1
rgb()
rgb(63 111 209)
半透明
/ 0.5
hsl()
hsl(220 62% 53%)

長さの単位

200px（固定）
50%（親の幅の半分）
20rem（ルート文字サイズ×20）
30vw（画面幅の30%）

em と rem の違い

親：font-size 20px

子：1.5em → 親の20px × 1.5 = 30px

子：1.5rem → ルート（html）の16px × 1.5 = 24px

ブラウザの設定で文字サイズを大きくしたユーザーにも対応できるよう、文字サイズには rem を使うのが一般的です。
